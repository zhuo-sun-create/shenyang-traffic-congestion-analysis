# Shenyang Traffic Congestion Analysis

A traffic data analysis project based on three-day traffic observations in Shenyang, China.

## Project Overview

This project analyzes urban traffic congestion during different time periods, including morning peak, off-peak, and evening peak hours.

Traffic data was collected from real-world road conditions in Shenyang and processed using Python.

## Tools

- Python
- pandas
- Matplotlib
- Folium
- CSV data processing
- GitHub Pages

## Analysis

The project includes:

- Three-day traffic data collection
- Morning, off-peak, and evening peak comparison
- Average traffic speed analysis
- Road congestion comparison
- Traffic data visualization
- Interactive traffic map

## Interactive Traffic Map

The interactive map visualizes traffic-related data in Shenyang and can be viewed directly in a web browser.

[View Interactive Traffic Map](https://zhuo-sun-create.github.io/shenyang-traffic-congestion-analysis/shenyang_traffic_map.html)

## Project Goal

The goal of this project is to apply traffic engineering knowledge and Python data analysis skills to real-world urban traffic data.

It demonstrates a basic workflow from traffic data collection and CSV processing to congestion analysis and interactive visualization.
